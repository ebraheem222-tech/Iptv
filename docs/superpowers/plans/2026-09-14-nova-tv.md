# Nova TV Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement the independent components with the API contract in the spec.

**Goal:** Deliver a runnable IPTV backend and shared Samsung/LG TV client for an existing Xtream subscription.

**Architecture:** Express serves the API, protected proxy, encrypted persistence, and built React app. TV packages bundle the same application with platform players and manifests.

**Tech Stack:** Node 22, Express 5, React 18, esbuild targeting Chrome 68, native video/AVPlay/hls.js, Node test runner, Playwright.

**Spec:** docs/superpowers/specs/2026-09-14-nova-tv-design.md

## Global constraints

- Support 2020-current Samsung Tizen and LG webOS; physical compatibility remains unverified until TV testing.
- Use the API field names and routes in the spec. Never expose provider credentials in API responses.
- Tests use local fixtures and demo media; never invent real subscription results.
- No transcoding, DRM removal, store publication, or automatic TV installation.

## Task 1: Secure backend foundation

Files: server/network.js, server/vault.js, server/media.js, tests/security.test.js.
Exports: safeFetch(url, options) validates/pins every DNS target and redirect; Vault({directory,key}) with create/get/update/delete session methods; MediaProxy with issue(url,sessionId), handle(req,res), revoke(sessionId). Use explicit constructor injection where test fixtures need private destinations.
- [ ] Write tests rejecting private/encoded loopback addresses and unsafe redirects, and preserving HLS resource queries/ranges.
- [ ] Run tests to see missing behavior; implement network guards, encrypted vault, bounded expiring media tickets and streaming HLS rewriting.
- [ ] Verify encryption, persistence and session expiry/revocation with isolated temporary directories.

## Task 2: Provider and application API

Files: server/provider.js, server/demo.js, server/app.js, server/index.js, tests/api.test.js.
Consumes Task 1 exports; produces all API routes in the spec.
- [ ] Write a fixture provider with exact Xtream actions, authentication rejection, streams, VOD details and two seasons.
- [ ] Write and run failing HTTP tests for connection, auth isolation, filtered catalogs, guide/details, favorite/progress persistence and play tickets.
- [ ] Implement validated provider adapter, bounded cache and routes. Serve dist and /artwork publicly; default bind 0.0.0.0:3000.
- [ ] Run API and security suite and fix behavior failures.

## Task 3: Television interface and player

Files: src/main.jsx, src/App.jsx, src/styles.css, src/components/*, src/lib/*, index.html, vite.config.js, tests/ui.spec.js.
Consumes all API routes. Browser dev proxy forwards /api and /media to port 3000. TV backend setting comes from localStorage or window.NOVA_CONFIG.apiBase; relative asset paths prefixed appropriately.
- [ ] Add browser flow tests: connect demo, browse/search, favorite, open seasons, launch player, return, logout, invalid login error.
- [ ] Build a polished dark living-room interface with lime accent, deliberate typography and remote focus styling.
- [ ] Implement async cancellation, loading/empty/error states, profile persistence and settings; use all real API routes.
- [ ] Implement native Samsung AVPlay, webOS native HLS and browser hls.js playback, media keys, cleanup and resume progress.
- [ ] Run browser checks and fix integration failures.

## Task 4: TV builds and operating instructions

Files: scripts/build.mjs, scripts/package-tv.mjs, tv/samsung/config.xml, tv/lg/appinfo.json, public/icon.png, Dockerfile, compose.yaml, .env.example, README.md.
